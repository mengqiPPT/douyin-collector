# 抖音视频收藏夹 · AI 智能分析版

> 一个基于 FastAPI + Vue3 的抖音视频收藏管理工具，支持自动解析、AI 内容分析、智能分类和全文检索，帮助你将零散的视频收藏转化为可检索、可分析的个人知识库。
>
> **在线体验**：[https://www.mengqihsh.icu](https://www.mengqihsh.icu)

---

## 一、项目简介与产品定位

### 1.1 项目简介

抖音视频收藏夹是一款面向知识工作者的视频内容管理工具。用户在刷抖音时经常会遇到有价值的内容（教程、科普、观点分享），但抖音原生收藏夹缺乏检索、分类和分析能力，导致收藏即"吃灰"。

本项目解决的核心痛点：
- **收藏分散** → 统一入库，结构化存储
- **无法检索** → 全文搜索（标题/描述/标签/AI摘要）
- **内容遗忘** → AI 自动生成摘要和要点，快速回顾
- **分类混乱** → 智能自动分类 + 手动调整

### 1.2 产品定位

| 维度 | 定位说明 |
|------|----------|
| **核心场景** | 个人视频知识库管理，将抖音收藏转化为可检索的学习资料库 |
| **目标用户** | 知识工作者、学习者、内容创作者——任何在抖音上获取知识并需要回顾整理的人 |
| **产品形态** | 双版本架构：本地版（主版本，长期使用）+ 在线 Demo 版（体验展示） |
| **核心价值** | 用 AI 将"被动的视频收藏"转化为"主动的知识资产" |

### 1.3 两种使用模式

| 模式 | 部署方式 | AI 能力 | 适用场景 |
|------|----------|---------|----------|
| **本地版** | 本地运行 | 完整（配置 API Key 后支持语音转写 + LLM 摘要） | 个人长期使用，数据本地存储 |
| **在线 Demo** | Vercel 部署 | 基础（无需配置，基于元数据的本地规则引擎摘要） | 作业展示、体验演示 |

## 三、核心使用流程与 AI 介入环节说明

### 3.1 整体使用流程

```
[用户粘贴抖音分享链接]
        ↓
[系统自动解析视频元数据]
        ↓
[视频入库 + 智能分类]
        ↓
[用户点击 "AI 分析"]
        ↓
[AI 引擎生成摘要 / 要点 / 标签]
        ↓
[用户通过搜索 / 分类 / AI 摘要回顾内容]
```

### 3.2 AI 介入环节详解

#### 环节 1：智能分类（入库时自动触发）

系统根据视频标题、描述、标签中的关键词，自动匹配预设分类规则，将视频归类到以下类别之一：

- 美食、科技、教育、娱乐、生活、财经、健身、旅游、设计、编程

用户可在详情弹窗中手动调整分类。

#### 环节 2：AI 内容分析（用户手动触发）

点击视频详情中的 **"AI 分析"** 按钮后，系统执行以下分析流程：

| 步骤 | 处理内容 | AI 能力 |
|------|----------|---------|
| ① 元数据提取 | 标题、作者、描述、标签 | 本地规则引擎解析 |
| ② 内容理解 | 识别技术工具、内容类型、目标受众 | 关键词匹配 + 规则推理 |
| ③ 摘要生成 | 生成 2-3 句话的结构化摘要 | 本地规则模板 + 动态填充 |
| ④ 要点提取 | 提取 3-5 个核心知识要点 | 基于内容类型定制要点 |
| ⑤ 标签推荐 | 生成 3-5 个 AI 内容标签 | 主题 + 类型交叉推荐 |
| ⑥ 分类优化 | 基于 AI 摘要重新建议分类 | 语义匹配 |

**在线 Demo 版本**：①~⑥ 全部基于本地规则引擎完成，无需外部 API。

**本地版本（配置 API Key 后）**：在 ① 之前增加 **语音转写** 环节（下载视频 → 提取音频 → 语音识别），并将 ③~⑤ 升级为 LLM 生成（更智能、更自然）。

#### 环节 3：AI 增强检索

搜索功能不仅匹配标题/描述/标签，还匹配 **AI 生成的摘要和要点**，实现深度内容检索。

例如：搜索 "Python" 时，即使视频标题中没有 "Python"，只要 AI 摘要在要点中提到了 Python 相关内容，该视频也会被召回。

## 四、启动方式与环境变量说明

### 4.1 快速开始（本地开发）

#### 环境要求

- Python 3.12+
- Node.js 18+
- FFmpeg（可选，仅 full 模式需要）

#### 启动后端

```bash
cd backend
pip install -r requirements.txt
python main.py
```

后端启动在 `http://localhost:8000`，API 文档：`http://localhost:8000/docs`

#### 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端启动在 `http://localhost:5173`

### 4.2 环境变量配置

本项目通过环境变量控制 AI 能力等级。所有环境变量均为**可选**，不配置时自动降级到本地规则引擎。

```bash
# ===== AI 分析增强配置（可选）=====
# 配置后将启用 "full" 模式：语音转写 + LLM 深度摘要

# 百度语音识别（用于音频转文字）
BAIDU_APP_ID=your_app_id
BAIDU_API_KEY=your_api_key
BAIDU_SECRET_KEY=your_secret_key

# 千帆大模型（用于 LLM 摘要生成）
QIANFAN_AK=your_access_key
QIANFAN_SK=your_secret_key

# DeepSeek API（备选 LLM 提供商）
DEEPSEEK_API_KEY=your_deepseek_key

# 通义千问 API（备选 LLM 提供商）
QWEN_API_KEY=your_qwen_key
```

**环境变量加载优先级**：系统环境变量 > `.env` 文件 > 代码默认值（空字符串）

### 4.3 AI 模式自动判定

系统启动时自动检测环境变量，动态选择 AI 工作模式：

| 检测条件 | 工作模式 | AI 能力 |
|----------|----------|---------|
| 百度语音 + 千帆 LLM 均配置 | `full` | 语音转写 + LLM 深度摘要 + 多模态封面分析 |
| 仅配置部分 API | `basic_plus` | 本地规则 + 可用 API 增强 |
| 无 API 配置（默认） | `basic` | 本地规则引擎（零配置可用） |

可通过访问 `/api/env-check` 查看当前环境配置状态。

## 六、功能特性

### 6.1 已完成功能

- **一键收藏** — 粘贴抖音分享链接，自动提取标题、作者、描述、标签、封面图
- **AI 内容分析** — 基于本地规则引擎识别视频主题、内容类型、目标受众，自动生成结构化摘要（无需外部 API 密钥也可工作）
- **智能分类** — 根据标签和描述关键词自动归类，支持手动调整
- **全文检索** — SQLite FTS5 全文搜索，支持跨标题、描述、标签、AI 分析摘要的多维搜索
- **卡片式浏览** — 响应式网格布局，支持分类筛选、状态标识、封面图代理加载
- **详情弹窗** — 居中小卡片展示视频完整信息，支持重新分析、分类编辑、跳转原视频
- **数据仪表盘** — 分类统计、收藏趋势、最近添加概览

### 6.2 AI 分析双模式

本系统支持两种 AI 分析模式，自动根据环境配置选择：

| 模式 | 触发条件 | 能力 | 成本 |
|------|----------|------|------|
| **basic（基础模式）** | 默认（无 API 密钥） | 基于视频元数据 + 本地规则引擎生成摘要、要点、标签 | 0 元 |
| **full（完整模式）** | 配置 API 密钥后 | 下载视频 → 提取音频 → 语音转写 → LLM 深度摘要 + 封面多模态分析 | 极低（DeepSeek 约 0.001 元/次） |

**在线 Demo 使用 basic 模式，零配置即可体验 AI 分析功能。**

## 七、API 概览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/videos` | 收藏视频（body: `{"share_text": "..."}`） |
| GET | `/api/videos` | 视频列表（query: `page`, `size`, `q`, `category`） |
| GET | `/api/videos/{id}` | 视频详情 |
| DELETE | `/api/videos/{id}` | 删除视频 |
| PATCH | `/api/videos/{id}` | 更新分类（body: `{"category": "..."}`） |
| POST | `/api/videos/{id}/analyze` | 触发 AI 分析 |
| GET | `/api/videos/{id}/analyze` | 查询分析状态/结果 |
| GET | `/api/categories` | 分类列表（含计数） |
| GET | `/api/env-check` | 环境检查（返回 AI 模式、组件可用性状态） |
| GET | `/api/proxy-image` | 封面图代理（解决跨域） |

详见 [DEVELOPMENT.md](DEVELOPMENT.md) 中的「API 详细说明」章节。

## 九、截图展示

### 数据概览仪表盘

数据概览页展示分类统计饼图、收藏总量、最近添加的视频卡片，帮助用户快速了解知识库全貌。
